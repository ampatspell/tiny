# Tiny

A Svelte library and a tool for building nice admin interfaces and custom public UIs based on SvelteKit, Kysely & SQLite3.

![](https://github.com/ampatspell/tiny/blob/master/static/screenshot-1.png?raw=true)

```sh
npx sv@latest create
# foof
# SvelteKit minimal
# Yes, using TypeScript syntax
# prettier, eslint, experimental
# @sveltejs/kit@next
# async, remote functions, explicit environment variables, rendering error boundaries
# npm
```

```sh
npm install @ampatspell/tiny --save
npm install-scripts approve -a
```

```sh
npx tiny
# Bootstrap this project
```

```sh
npm run dev
```

First user that signs-up gets `admin` role.
